GRZ SKY LIGHTING RESOURCE FINDER

1. Close DayZ. Extract this ZIP.
2. Double-click Extract-Sky-Lighting.cmd.
3. Select your DayZ GAME installation folder (contains DayZ_x64.exe).
4. It opens Desktop\GRZ-Sky-Lighting. Send the extracted lighting TXT files.
   If none were copied, send Lighting-files.txt from that folder instead.

This reads PBO file tables under Addons and dta and extracts only the small
lighting_default.txt / lighting_darknight.txt resources when uncompressed.
It does not modify game files, install anything, or upload any information.
It does not scan profiles, credentials, other Steam games or user documents.
